# ADR 0003: licença AGPL-3.0

- **Data:** 07/11/2026
- **Situação:** aceita (GXP-8).

## Contexto

O escopo fixa o repositório público com AGPL-3.0 (decisão 1). Há também um motivo técnico:
a engine de duelo (`ygopro-core`) e os scripts de carta (`CardScripts`) são AGPL-3.0 (veja
os arquivos `LICENSE` e `COPYING` dos submódulos), e o Rails carrega a engine como
biblioteca, no mesmo processo (FFI, ADR 0001). O programa que roda é uma obra só, então
segue a licença da engine.

A AGPL vai além da GPL num ponto: quem usa o programa **pela rede** tem direito ao
código-fonte da versão que está rodando (seção 13).

Nomes, textos e imagens das cartas, e a marca do jogo, são da Konami. Não são nossos para
licenciar.

## Decisão

1. **Todo o código do repositório é AGPL-3.0** (backend, frontend, workflows e scripts),
   pelo arquivo `LICENSE` na raiz. Contribuição entra na mesma licença, sem CLA.
2. **Seção 13:** o rodapé do site tem o link "Código-fonte" para o repositório. A produção
   sai sempre de um commit da `main` (o `vercel.json` só publica a `main`), e os submódulos
   fixam o commit da engine, dos scripts e do BabelCDB. Quem joga acha no GitHub exatamente
   o que está no ar.
3. **Dependência nova só com licença compatível com a AGPL-3.0:** MIT, BSD, ISC, Apache-2.0,
   MPL-2.0, LGPL, GPL-3.0 ou AGPL-3.0. Licença "só GPL-2.0" não serve. Quem adiciona confere
   no PR.
4. **Conteúdo de terceiros fica fora do código e com a regra de cada fonte:**
   - BabelCDB não declara licença: entra só como submódulo, e os `.cdb` só são copiados para
     a imagem do container (ADR 0001, decisão 3).
   - Textos e nomes mostrados ao jogador (F1) vêm da Yugipedia (CC BY-SA), com crédito.
   - Imagens das cartas (F1) vêm do YGOPRODeck, são baixadas uma vez e hospedadas por nós
     (escopo, 3.2), **fora do repositório** (ADR 0004).
   - O nome comercial do jogo de referência não aparece no repositório; o código e os
     documentos dizem "jogo de referência".
5. **Sem fins lucrativos:** sem anúncio, sem venda, e DP não se compra com dinheiro. O
   README e o rodapé dizem que é projeto de fã, sem ligação com a Konami. Isso também é
   condição do plano Hobby da Vercel (ADR 0004).

## Consequências

- Quem rodar uma cópia modificada como serviço precisa publicar o código dela.
- Um PR que traga código copiado de outro projeto precisa dizer de onde veio e com qual
  licença.
- Pedido de retirada de conteúdo (imagem, texto) se resolve tirando o conteúdo do ar, sem
  mexer no código.

## Alternativas descartadas

- **MIT ou Apache-2.0 no nosso código:** o programa que roda, junto com a engine,
  continuaria AGPL. Duas licenças no mesmo repositório só confundiriam.
- **Engine num serviço separado, para "isolar" a AGPL:** o código já é aberto, então não há
  o que isolar, e um salto de rede a mais em cada ação pesaria na meta de 300 ms.
